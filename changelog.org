* Unreleased

** Added
- Monochrome type icons (article/document, video/movie, podcast/mic,
  course/cap, book, tool/wrench) shown at the bottom of each card before the
  source domain, with the type name as tooltip; replaces the colored type
  pills while topic tags stay at the top.
- About page (/About) explaining the mission, ranking/visibility rules, how to
  browse, vote, post, search, mark as read and archive; linked from the
  sidebar menu for everyone.
- Mark as read: a check button on every feed card hides that link from the
  feed for the current user (per-account =ReadLink= table, unique user+link,
  indexed, so it scales without loading client state).
- =Already read= page (/AlreadyRead) listing the user's read links newest
  first, each with an unmark button that restores it to the feed.
- Archive: a bookmark button on feed cards saves a title+URL snapshot
  (=ArchivedLink= table, unique user+URL, no link FK) that survives feed
  expiry and link deletion. The /Archive page lists snapshots with delete.
- Burger menu sidebar (native <dialog>) with Feed, Archive and Already read
  for logged-in users; guests get Log in + Register pinned at the bottom,
  logged-in users get their name/email and Log out there. The panel docks to
  the right edge, matching the burger's position.
- Monochrome icons added to every sidebar item and account button (feed,
  archive, already read, about, log in, log out, register); About moved to
  the docked bottom section, just above the account block.
- Mark-read / archive / unmark / delete actions post via fetch with the
  antiforgery token and update the page in place; plain form posts still work
  without JavaScript.
- =UserLinkStateService= with tests for idempotent read/archive, snapshot
  survival, and owner-scoped archive deletion.
- Minimal UI: filter bar removed from the page, everything consolidated into
  a click-to-open search overlay behind a header search icon (search box,
  type filters, sort radios, tag input).
- Nested tags replace the Topic enum: hierarchical =Tag= entity with paths
  like =science/physics=, =LinkTag= join table, up to 4 levels deep, free-form
  creation when adding a link (max 5 per link).
- Typeahead for tags everywhere (search overlay and add form) via a new
  =GET /tags?q= JSON endpoint returning full paths with link counts.
- Tag filtering with an Any/All match-mode toggle (Any is the default).
- Active-filters strip under the header showing every applied filter/search
  as a removable chip, with clear-all.
- =NestedTags= migration converting existing Topic values to tags.
- Add button moved from bottom-center FAB to docked, centered in the header
  top bar.
- Admin account: =IsAdmin= on User, =Admin= config section, admin ensured on
  every startup, =Role: Admin= claim issued at login for future admin pages.
- Site favicons on cards (DuckDuckGo icon CDN, domain as tooltip) instead of
  the plain domain text.
- Upvoting without page reload: fetch-based vote with in-place count/state
  update, antiforgery token from a meta tag, redirect fallback for no-JS.
- EF Core migrations: local =dotnet-ef= tool, InitialCreate migration,
  =MigrateAsync= at startup replacing EnsureCreated.

** Changed
- Feed page title/tagline ("legit-content · Escape the brain-rot...") removed
  for a more minimal feed; the brand stays in the top bar.
- Card read/archive controls moved to the right edge, stacked vertically;
  upvote stays on the left.
- Auth controls (name, log out, log in, register) moved out of the top bar
  into the burger sidebar footer, and the burger itself docked on the right.
- LICENSE template updated: the program name and description now say
  legit-content / "a curated feed of legit content" instead of chrono.
- Feed cards show tag badges instead of the topic badge.
- Tests grew to 32 (TagService hierarchy/validation/search, TagMatcher
  match modes, LinkService updated for tag paths).

** Fixed
- Closed sidebar dialog was visible at the bottom-left of non-feed pages:
  the author `.side-panel { display:flex }` rule overrode the native
  `dialog:not([open])` hidden state. Display flex is now scoped to
  `.side-panel[open]`.
- URL normalization dropped query strings, so two different YouTube videos
  (=youtube.com/watch?v=A= vs =?v=B=) were rejected as duplicates.
  =NormalizeUrl= now keeps the query; regression test added.

** Added
- Serilog logging: rolling daily files at =~/magnus/legit-content/logs/=,
  request logging middleware, 14-day retention.
- Project docs: README.org, plans-and-todos.org, bugs.org, changelog.org,
  LICENSE (GPL-3.0), run.sh launcher.

* 0.1.0 — 2026-11-17

Initial version.

** Added
- One-page feed: link cards with type/topic badges, source domain,
  submitter, age, description.
- Filters: type chips, topic chips, Most-legit/Newest sort, search.
- Ranking: upvotes + 3-day freshness boost (LinkRanker).
- Visibility rule: posts always visible for their first 30 days, then hidden
  only with 0 upvotes.
- Upvote-only voting with toggle; anonymous votes redirect to login and back.
- Add-link dialog (native <dialog>), floating + button bottom-center.
- Anti-spam: 5 links/day/user, duplicate-URL rejection with normalization,
  http(s)-only validation.
- Accounts: email/password registration, login, logout, 30-day sliding
  cookie session, hashed passwords.
- Light/dark theme toggle with the custom palette.
- Seed data: 19 curated legit links + 5 demo users (unguessable passwords).
- SQLite database auto-created and seeded on first run.
- 16 unit tests (link ranker, link service, user service).
